## 💡 The Problem

In Mexico's Traditional Channel (tienditas de abarrotes), distributor field agents — called *preventistas* — visit hundreds of small stores every week. But without data, they can't tell which stores are about to stop buying until it's already too late.

**Churn Hunters was born from one question: what if a preventista could walk into their day already knowing exactly which stores need attention and why?**

---

## 📱 What is Churn Hunters?

Churn Hunters is an iOS app with a real ML churn prediction model and an AI agent that turns raw data into field-ready decisions.

### 🏠 Smart Store Dashboard
A prioritized daily route for the preventista — showing the top stores by churn risk, with liquid-fill gauges, transaction data, cooler status and territory breakdown. One tap reveals the full store detail and AI-generated diagnosis.

### 🤖 Churn Hunter Agent
An AI agent powered by Gemini 2.0 Flash that analyzes each store's data and generates:
- A **diagnosis** of why the store is at risk
- A **projection** of what happens if no action is taken
- A **concrete action** the preventista should take today

The agent also generates executive briefings, territory reports, and full period analysis — all from real ML predictions.

### 📊 Executive Dashboard & Reports
Full period analysis with risk distribution charts, territory rankings, subchannel breakdown, trend projection and a prioritized action plan — all generated autonomously by the AI agent.

### 📋 Surveys (Encuestas)
NPS satisfaction tracking with animated gauge, territory breakdown and per-store survey history.

## 🚀 Getting Started

### 1. Generate predictions (ML model)

```bash
cd ml
pip install -r requirements_ml.txt

# Full dataset (450 records)
python pipi_corregido.py

# Quick test (20 records)
python pipi_20.py
```

Required files in the same folder:
```
sales_churn_train.csv
sales_churn_test.csv
Coolers.csv
Clientes.csv
```

### 2. Add JSON to the iOS app

Drag `churn_predictions.json` into your Xcode project bundle.

### 3. Configure your API key

1. Go to [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
2. Create a new key under a new project
3. Replace the key in the three Swift services:

```swift
// GeminiService, AgentBannerService, ReportService
static let apiKey = "YOUR_KEY_HERE"
```

### 4. Run the backend (optional)

```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
echo "GEMINI_API_KEY=your_key_here" > .env
uvicorn app.main:app --reload
```

API docs available at `http://localhost:8000/docs`
